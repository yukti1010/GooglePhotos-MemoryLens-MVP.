## Brand & Style

This design system blends pristine, utilitarian photo management with humanistic memory curation. It merges the disciplined spatial clarity of modern product design with the tactile intimacy of an editorial scrapbook. Rather than presenting machine intelligence through sterile robotic tropes, the system approaches recall with emotional resonance, curiosity, and warmth.

The target audience spans everyday archivists, families, and storytellers seeking meaningful reflection over transactional media scrolling. The interface elicits quiet wonder, safety, and nostalgic joy.

Key visual attributes:
- **Quiet Canvas:** Crisp, ultra-clean white surfaces with balanced neutral containers that prioritize photographic imagery without chromatic competition.
- **Humanistic Serendipity:** Expressive typographic rhythm paired with focused iris violet accents, signaling synthetic intelligence as a thoughtful curator rather than an analytical engine.
- **Editorial Micro-Moments:** Memory arcs, contextual tags, and narrative prompts treated as organic journal entries rather than clinical database queries.

## Colors

The palette establishes an airy, light-first canvas where photographs take primary visual hierarchy, supported by an expressive tonal violet system for synthesis, insights, and discovery prompts.

### Palette Architecture
- **Primary (`#7C3AED` - Iris Accent):** Directs primary interactive milestones, conversational query pills, semantic memory prompts, and affirmative selection states.
- **Secondary (`#2563EB` - Clear Cobalt):** Employed selectively for standard navigation controls, link highlights, and secondary system-level confirmations.
- **Tertiary (`#059669` - Sage Emerald):** Denotes verified temporal clusters, completed memory reconstructions, and positive recognition signals.
- **Neutral Core (`#1F2937` to `#FFFFFF`):** High-legibility text hierarchy structured against pristine off-whites:
  - Canvas Base: `#FFFFFF`
  - Surface Subdued: `#F9FAFB`
  - Surface Dim: `#F3F4F6`
  - Outline Subtle: `#E5E7EB`
  - Outline Crisp: `#D1D5DB`
  - Text Primary: `#111827`
  - Text Secondary: `#4B5563`
  - Text Tertiary: `#9CA3AF`

### Semantic Tonal Badges
Micro-metadata cards and semantic retrieval cues utilize delicate pastel tinted backgrounds with deep harmonic foregrounds:
- **Violet Memory Cue:** Background `#F5F3FF`, Text `#6D28D9`
- **Azure Location Cue:** Background `#EFF6FF`, Text `#1D4ED8`
- **Amber Temporal Cue:** Background `#FFFBEB`, Text `#B45309`
- **Emerald Person/Face Cue:** Background `#ECFDF5`, Text `#047857`

## Typography

The type pairing merges structured precision with expressive storytelling:
- **Headline Font (`Bricolage Grotesque`):** Delivers a crafted, contemporary editorial voice for conversational memory headings, time-capsule themes, and memory highlights. Its eccentric geometric quirks instill emotional personality without sacrificing readability.
- **Body & Label Font (`Hanken Grotesk`):** Provides a modern, crisp grotesque canvas for metadata, narrative prose, image summaries, and user interface controls.

### Implementation Rules
- Keep conversational AI prompts in `headline-md` or `title-md`, avoiding dry command-line text styles.
- Use `label-sm` with upper-case tracking only for micro-temporal tags (e.g., "OCTOBER 2021 · GOLDEN HOUR").
- Narrative story descriptions should never exceed 65 characters per line to maintain book-like reading cadence.

## Layout & Spacing

The layout is built around a responsive dynamic grid engineered for asymmetric image curation, fluid narrative scannability, and contextual search drawers.

### Grid Framework
- **Mobile (<600px):** 4 fluid columns, `margin: 1rem`, `gutter: 1rem`. Bottom sheets host contextual query refinements.
- **Tablet (600px - 1024px):** 8 fluid columns, `margin: 2rem`, `gutter: 1.5rem`. Split memory canvas with parallel prompt inspection.
- **Desktop (>1024px):** 12 fluid columns, `margin: 3rem`, `gutter: 2rem`. Maximum container width capped at `1440px` centered to maintain balance across expansive displays.

### Rhythm Principles
- Memory chapters rely on `space-xl` for breathing room between dates or distinct emotional themes.
- Metadata chips and contextual tags cluster tightly using `space-xs` and `space-sm` gaps.
- Photo clusters honor variable aspect ratio mosaics (1:1, 4:5, 16:9) arranged along rhythm lines rather than rigid, monolithic square crops.

## Elevation & Depth

Visual hierarchy uses clean surface separation, ultra-diffused atmospheric ambient shadows, and gentle ghost outlines to emulate layered paper memorabilia floating softly over an illuminated table.

### Surface Hierarchy
- **Level 0 (Base Canvas):** `#FFFFFF` flat foundation.
- **Level 1 (Subtle Inset / Context Cards):** `#F9FAFB` bounded by a 1px border of `#E5E7EB`. Used for passive metadata cards, inactive query filters, and cluster containers.
- **Level 2 (Active Memory Cards / Chips):** Elevated with a subtle ambient drop shadow: `0px 2px 8px -2px rgba(17, 24, 39, 0.05), 0px 1px 3px 0px rgba(17, 24, 39, 0.06)`, framed by a crisp border of `#E5E7EB`.
- **Level 3 (Interactive Drawers, Modals & Floats):** Elevated with an ambient memory shadow: `0px 12px 32px -4px rgba(124, 58, 237, 0.08), 0px 4px 12px -2px rgba(17, 24, 39, 0.04)`. Imparts soft illumination tinted with the violet primary seed.

### Depth Rules
- Never use heavy, high-contrast, sharp drop shadows.
- Avoid pure glassmorphism blurs on critical imagery; restrict blur overlays strictly to floating query app-bars and navigation pills (`backdrop-blur-md` at 85% opacity `#FFFFFF`).

## Shapes

With a roundedness index of `3`, the design system adopts generous, fluid pill forms and sweeping corner geometry, creating a welcoming, tactile experience:

- **Interactive Pills (`rounded-full` / 9999px):** Standard buttons, search prompt capsules, filter chips, confidence indicators, and audio memory triggers.
- **Primary Memory Cards (`rounded-2xl` / 2rem):** Story cards, image groupings, memory summaries, and modal viewports.
- **Sub-Containers (`rounded-lg` / 1rem):** Image thumbnails within cards, context tooltips, and nested metadata groups.
- **Media Containers:** Image assets inside story panels inherit matching corner radii (`rounded-2xl`) to avoid harsh visual edges against the fluid canvas.

## Components

### Buttons & Interactive Pills
- **Primary Action (Story Synthesis):** Fully pill-shaped (`rounded-full`), filled with `#7C3AED`, displaying `label-lg` white text. Hover transitions to `#6D28D9` accompanied by a micro-scale transition (`scale-102`).
- **Tonal Filter Chips:** Fully pill-shaped (`rounded-full`), background `#F3F4F6`, border 1px solid `#E5E7EB`, text `#4B5563`. When activated: background `#F5F3FF`, border 1px solid `#C4B5FD`, text `#6D28D9`.
- **Icon Actions:** 40x40px pill or circular bounds, hover background `#F3F4F6`, with 20px optical center iconography.

### Cards & Story Clusters
- **Progressive Memory Disclosure Card:** Built with `rounded-2xl` corners, 1px border in `#E5E7EB`, and `space-lg` padding. Features an editorial `Bricolage Grotesque` headline (e.g., "Sunday afternoon in Montmartre"), followed by a chronological image arc, an intelligent synthesized summary, and bottom-anchored metadata pills.
- **Scrapbook Cluster Card:** Displays off-grid, gently angled image overlaps (restricted to -1.5deg to +1.5deg) with clean white borders (4px white halo) resting inside an elevation-2 surface container.

### Confidence & Metadata Badges
- **Retrieval Confidence Badge:** Subtle micro-pill (`rounded-full`, 24px height) displaying an iris dot indicator alongside `label-sm` text (e.g., "94% semantic match").
- **Story Cue Metadata Tag:** Tiny contextual capsule using the designated semantic pastel backgrounds (e.g., pale amber for time cues, pale emerald for location cues) with 4px inner dot indicators.

### Input Fields & Retrieval Prompts
- **Conversational Search Bar:** Floating pill container (`rounded-full`) at 56px height, elevated at Level 2, with 16px horizontal internal spacing. Border 1px solid `#E5E7EB`, focusing smoothly to a 1.5px border of `#7C3AED` with no harsh outline rings. Houses contextual prompt suggestions as horizontally scrollable chips beneath.

### Lists & Chronological Arcs
- **Timeline Arcs:** Vertical connecting track using 2px dashed `#E5E7EB` interrupted by solid `#7C3AED` milestone dots. List items use asymmetric row heights to celebrate varied image dimensions, avoiding rigid spreadsheet monotony.
